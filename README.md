# my-project

Dự án mới, quản lý bằng Git trên máy này.

## Trạng thái

- Nhánh mặc định: `main`
- Remote: chưa gắn. Cursor Origin (`origin.cursor.com`) chưa hỗ trợ Windows gốc (chỉ macOS, Linux và WSL).

## Bước tiếp theo

Khi đã có địa chỉ remote (GitHub hoặc máy khác):

```bash
git remote add origin <url>
git push -u origin main
```
